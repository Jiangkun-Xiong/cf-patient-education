Use [site-map.json](site-map.json) as a content inventory. It is documentation at this stage and does not automatically generate the website.

When rebuilding a page, record its original URL, review its text and references, add its HTML under `docs/`, and update its `migrationStatus`. Move a navigation link to the new page only when that page exists and has been checked.

Keep source references beside the claims they support. For original media, add the files you own or retain the original source links and credit.
